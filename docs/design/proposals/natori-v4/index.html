名取LP デザイン案 第4弾（D-3「帯」の展開）

D-3「帯」をもとに、トップ画面の見せ方と色の配分を変えた3パターンです。写真はすべて仮置きです。

  • D-3 帯（元の案）黄色地。菱形を4本の帯に切ってトップに置く。
  • D3-1 白帯白地。見出しの1行ずつが黄色い帯に乗る。補助金のセクションは黒。いちばん上品。
  • D3-2 写真×帯全面の写真に、見出しの黄色い帯と相談ボタンの黒い帯を重ねる。撮影写真が入ると映える。
  • D3-3 数字×帯帯の中に「10万円」と「2026.12.31」を書き込む。広告から来た人に、補助金の額と期限が一目で伝わる。
