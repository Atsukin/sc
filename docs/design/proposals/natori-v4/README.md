# 名取LP デザイン案 第4弾（2026-11）— D-3「帯」の展開

第3弾の D-3「帯」が最有力。その方向のまま、トップ画面の見せ方と色の配分を変えた3パターン。
2つ目のセクション以降は D-3 と同じ組み方（帯の階段・8段の流れ・斜めの区切り）で、配色だけ変えている箇所がある。
写真はすべて仮置き（`../natori-v3/img/` を参照）。

## D3-1「白帯」
- 白地。見出しの1行ずつが黄色い45度の帯に乗り、ロゴの菱形のように左へずれる
- トップの4本の帯は、写真2本・黒・黄
- 補助金のセクションを黒地にして「10」を黄色に。黄色の面積が減るぶん、いちばん上品

## D3-2「写真×帯」
- 全面の写真の上に、白い帯（地域名）・黄色い帯（見出し）・黒い帯（説明と相談ボタン）を重ねる
- 3つの特徴（10万円・年中無休・手倉田に本社）は写真の下の白い帯に
- 撮影した施工写真に替えると、いちばん映える

## D3-3「数字×帯」
- 見出しを「名取市の補助金で、太陽光と蓄電池を。」にして、検索語と広告の文言にそろえる
- トップの黒い帯に「10万円」、白い帯に「2026.12.31」を書き込む。額と期限が一目で伝わる
- 補助金の受付が終わったら、帯の中身を差し替える必要がある（季節ごとに入れ替える運用）
