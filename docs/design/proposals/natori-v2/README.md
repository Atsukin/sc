# 名取LP デザイン案 第2弾（2026-11）

第1弾（`../natori-fv/` の A/B/C、LP への着せ替え）は「まだ普通」という評価。
「もっと格好良く」に応えるため、既存 LP の構成に縛られず、見せ方の発想から変えた3案。
写真はすべて仮置き。採用後に SC の施工写真・撮影素材へ入れ替える前提。

共通: 色はロゴの黒 `#040000` と黄 `#F5E528` / 角丸なし / 書体は Noto Sans JP（300〜700、極太は使わない）/ 未確認の表現（無料など）は使わない

## D案「菱形」— ロゴそのものを写真の窓にする
- ロゴの菱形（45度の平行四辺形4枚）を画面いっぱいに描き、2枚に写真、2枚にロゴの黄色を入れる。読み込み時に4枚が組み上がる
- 補助金は黄色の斜めの帯に、巨大な「10」万円
- ブランドの形をそのまま使うので、ほかのどの会社とも似ない。HP にも展開しやすい

## E案「シネマ」— 全画面の写真を1枚ずつ（自動車メーカーの見せ方）
- 1画面に1つのメッセージ。文字は最小限、細めの見出し、数字は諸元表のように
- 「電気を、買う家から つくる家へ。」→ 補助金 → 停電への備え → 相談
- いちばん高級感が出る。その分、写真の質がそのまま仕上がりを決める（撮影が必須）

## F案「エネルギーフロー」— 電気の流れを図で動かす
- 黒地に、太陽・家・蓄電池・電力会社の図。「昼／夜／停電」を押すと電気の流れが切り替わる
- 写真に頼らないので、撮影前でも完成度が出せる。仕組みが一目でわかり、広告からの離脱も防ぎやすい
- テック寄りの格好良さ。住宅会社らしい温かみは3案でいちばん弱い
