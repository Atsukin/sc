# 名取LP ファーストビュー デザイン案（2026-11）

先方の指摘「丸みがあって安く見える」「もっと格好良くスタイリッシュに」を受けた作り直し。
ファーストビュー（最初の1画面）だけを3パターン作り、方向性を選んでもらう。選ばれた方向で LP 全体 → HP へ展開する。

## 3案に共通するルール
- 色はロゴから取る。黒 `#040000`、黄 `#F5E528`（菱形の上半分）、淡い黄 `#F7EE80`（下半分）。旧 LP のオレンジ・水色は使わない
- 角丸を使わない。ボタンも写真も直角。ロゴの菱形の「斜めの直線」を造形のよりどころにする
- 極太ゴシックをやめる。ゴシックは Zen Kaku Gothic New（字面が四角く、丸みが出にくい）、明朝は Shippori Mincho
- 「無料」など社内確認が済んでいない表現は使わない（docs/release-solar-natori.md）。数値は確認済みの補助金の内容だけ
- 写真は現状フリー素材。採用後は SC の施工現場・名取の住宅で撮影し直す前提

## A案「昼の家」— 写真と余白で信頼感（参考: Sunrun）
- 白地。左に見出しと相談ボタン、右に住宅の写真を大きく
- 下に「補助 1件10万円／設置期限／本社」の3項目を細い線で区切って置く
- 一番クセがなく、地域の住宅会社として信頼されやすい。広告にも SEO にも合わせやすい

## B案「夜の明かり」— 力強さと高級感（参考: Otovo / Enpal）
- 暗く落とした屋根の写真に、白の大きな見出し
- ロゴの菱形を大きく切り取った黄色の線を、画面の右に重ねる。ここだけが目立つ要素
- 黄色は相談ボタンと菱形だけ。黒×黄のロゴがいちばん映える案

## C案「縦書きの明朝」— 和の格（地元企業の品格）
- 白地に明朝体の縦書きの見出しと、名取の町の朝日の写真
- ロゴの「SC」が明朝系なので、文字の印象がロゴと揃う
- ほかの太陽光業者とまったく違って見える。一方で、広告 LP としての「押しの強さ」は3案で一番弱い
