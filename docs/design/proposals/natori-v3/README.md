# 名取LP デザイン案 第3弾（2026-11）— D案「菱形」の展開

第2弾（`../natori-v2/`）で D案「菱形」が採用候補に。その方向で、LP の全セクションまで作った3パターン。
写真はすべて仮置き。採用後に SC の施工写真・撮影素材へ入れ替える前提。

共通:
- 色はロゴの黒 `#040000`、黄 `#F5E528`、淡い黄 `#F7EE80`。角丸なし。書体は Noto Sans JP（300〜700）
- 角度はロゴの平行四辺形と同じ45度だけを使う
- 構成と文言は現行 LP（`src-next/src/app/solar/natori/`）と同じ。お悩み → 補助金 → 対象/対象外 → 5つの条件 → 宮城県 → 流れ → 相談 → 名取市のポイント → 停電 → 理由 → FAQ → 相談
- 未確認の表現（無料、専門スタッフ、浸水想定の提案）は外した。塩害と SII 要件は `TODO(要確認)` のまま残している

## D-1「白・建築」— 第2弾 D案をそのまま全体に
- 白地。ファーストビューはロゴの菱形を写真の窓にしたもの
- 各セクションの写真は「左上と右下を45度に落とした」形でそろえる
- 補助金は黄色の斜めの帯に「10」万円。流れは8つの平行四辺形が右へ進む
- いちばん落ち着いていて、HP 全体に広げやすい

## D-2「夜」— 黒地で、黄色を電気の光として使う
- 屋根のパネル写真の上に、ロゴの菱形を線で描き、1枚だけ黄色く灯る（読み込み時の唯一の動き）
- 写真はロゴと同じ平行四辺形（縦横比 2:1）で切り抜く
- 停電のセクションは全画面の写真。最後の相談だけ黄色に反転させる
- いちばん高級感が出る。暗い写真が多いと重くなるので、写真の選び方が大事

## D-3「帯」— 黄色地で、菱形を帯に分解する
- ロゴの菱形を4本の45度の帯に切り、2本を写真、黒と白を1本ずつにしてファーストビューに置く
- お悩みは帯が階段状に重なる。流れは8段の帯が右へ上っていき、最後の「補助金の入金」が黒
- 見出しを特に大きくし、いちばん強く印象に残る。広告から来た人の目を止めやすい
