# /solar/natori/ デザイン計画

`.claude/skills/frontend-design/SKILL.md` の手順（計画 → 見直し → 実装 → 批評）に従って作る。

## ブリーフ
- **題材:** 名取市の戸建て住宅に、太陽光発電と蓄電池を入れること
- **読み手:** 名取市の持ち家世帯（40〜60代が中心）。電気代の値上がりと震災の停電の記憶があり、訪問販売を警戒している。スマホで読む人が多い
- **このページの役目:** 12/31 の補助金の期限までに、「まず電話で相談」してもらう
- **信頼の源:** 名取市に本社がある、役所の情報を正確に案内する、押し売りしない

## トークン

### 色（ロゴから取る）
| 名前 | HEX | 用途 |
|---|---|---|
| Lemon | `#F2E42B` | ロゴの濃い黄色。CTA と期限の強調だけに使う |
| Lemon Pale | `#F8EF8C` | ロゴの淡い黄色。マーカー、表の強調行 |
| Ink | `#000000` | ロゴの「SC」の黒。見出しとボタンの文字 |
| Body | `#33312C` | 本文。純黒より少し柔らかくして、長文を読みやすくする |
| Cell Blue | `#1D4B8F` | 太陽電池セルの青。補助金の金額と出典のリンク（情報の色） |
| Sky | `#E8F0F6` | 晴れた空の淡い青。交互に使う背景（クリーム色は使わない） |

今の黄緑（#D4E157）は、ロゴの色と合わないので廃止する。

### 書体
- **見出し:** Zen Old Mincho（ロゴの「SC」の明朝体に合わせる）。h1 と h2 だけに使う
- **本文・UI:** Noto Sans JP。本文は 17px、行間は 1.9（年配の読み手を想定）
- **数字:** 金額や日付も明朝体で大きく出す。等幅フォントは使わない

### レイアウト
- **左揃え・1カラム。** 本文の幅は最大 40 字（約 680px）。写真と表だけを広げて、リズムをつくる
- **背景:** 白と Sky を交互に使う。濃い色の面は、最後の CTA の1か所だけにする
- **角:** 写真は角を丸めない。ボタンだけ 4px の角丸にする。カードの影はやめ、区切りは罫線と余白で表す

### 原則
1. **大胆にするのはロゴの 45° だけ。** ファーストビューの写真の切り取りと、期限の帯の2か所で使う。ほかは静かに保つ
2. **役所の案内のように正確に、町の会社らしく親しみやすく。** 補助金の部分は、公的な通知の見た目（罫線の表、条項番号、出典）にして信頼性を出す
3. **飾りの言葉を削る。** 英字の小見出し、「→」、意味のない番号はつけない。番号は、本当に順番がある「流れ」と「スケジュール」だけに使う
4. **アニメーションはなし。** 開閉など、操作に応える動きだけにする

## 見直し（スキルの「よくある既定パターン」との照合）
| 前回の実装 | 該当する既定パターン | 変更内容 |
|---|---|---|
| 全見出しの上の英字ラベル（WORRIES など） | 大文字の小見出しのテンプレート | 削除する。見出しそのものを明確にする |
| 同じ角丸カードと影の繰り返し | SaaS のカード部品 | お悩みは、罫線とマーカーのチェックリストに。条件は、条項風の番号付きの表に |
| 濃紺の面と黄緑の差し色 | 黒背景と鮮やかな差し色1色 | 濃い面は最後の CTA だけにする。差し色はロゴのレモン色にする |
| 01/02/03 の番号（選ばれる理由など） | 意味のない番号 | 順番のない内容から番号を外す |
| リンク末尾の「→」 | テンプレートの飾り | 削除する |
| 大きな数字の帯（10万円／12/31／9:00〜21:00） | 大きな数字＋小さなラベルの帯 | やめる。金額は補助金の表の中で大きく、期限はストライプの帯だけで見せる |
| すべての節が写真＋カード | 決まった型の繰り返し | 写真を使うのは、ファーストビュー・設置のポイント・停電の3か所に絞り、残りは文字組みで見せる |

初案では「黒背景に黄色い数字のヒーロー」も考えたが、上の2つ目のパターンそのものなので捨てた。
