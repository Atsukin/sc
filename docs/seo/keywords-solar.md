### 評価の基準
- **CVへの近さ**: A = 業者を探している・見積もりを取りたい（問い合わせに直結） / B = 補助金・費用など、導入を前提に比較している / C = 情報収集の段階
- **ボリューム（相対）**: 大 / 中 / 小 / 極小
- **競合**: 強 = 全国の大手メディア・大手施工会社・自治体事業が上位を占める / 中 = 補助金のまとめサイトと一部の業者 / 弱 = 名簿サイト・PDF・まとめサイトが中心で、地域の業者の専用ページがほぼない
- **優先度**: P1 = フェーズ4で作る / P2 = フェーズ4〜6 / P3 = フェーズ6以降、またはコンテンツの一部で拾う

## 3. 優先順位のまとめ

1. **P1（フェーズ4で作る）**: N1〜N7（`/solar/natori/`）、N4・N5・G1（`/solar/subsidy/`）、ハブ `/solar/`
2. **P2**: `/solar/blackout/`（N8・G4）、`/solar/faq/`、岩沼・亘理の補助金（I2・W2）を補助金ページに入れる、卒FIT・後付け（G5）
3. **P3（フェーズ6）**: `/solar/iwanuma/` → `/solar/sendai/` → `/solar/watari/`、`/solar/v2h/`、`/solar/cost/`

### 優先する理由
- 名取市は本社所在地で、「地元の会社」という最大の差別化が効く。競合も弱い
- 「名取市 蓄電池 補助金」の上位は補助金ポータルで、**太陽光単体は対象外**、**事後申請**、**2026年12月31日までに電力受給開始が必要**、**リース・PPA は対象外**といった、申請の可否を分ける要件が書かれていない。市の申請の手引き（PDF）に基づいて正確に書けば、情報の質で上回れる
- 岩沼市は前期（7月）の受付が終わっており、後期は2026年12月〜2027年1月。フェーズ6の公開を後期の受付前（11月中）に合わせられると良い
